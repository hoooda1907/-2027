RMT System — خطوات الرفع على GitHub
1) أنشئ مستودعًا جديدًا فارغًا (أو احذف كل الملفات القديمة من مستودع RMT System) ولا تضعه مع النسخة السابقة.
2) ارفع كل محتويات هذا المجلد بنفس الأسماء والمسارات (بما فيها .github) ثم Commit.
3) Actions -> انتظر علامة ✅ -> Artifacts -> rmt-system-windows
   RMT-System-Setup.exe (تنصيب)  |  RMT-System-Portable.exe (بدون تنصيب)
- خطوة check في البناء تتوقف وتعرض الملفات الناقصة لو الرفع ناقص.

مسار الحفظ: D:\RMT System (وإن لم يوجد القرص D فمجلد المستندات)
  نقطة البيع\الفرع\التاريخ\الجلسة\ | المشتريات | المخزون | التصنيع | العملاء | الموارد البشرية | الحسابات | النسخ الاحتياطي (كل ساعتين)

الربط مع أودو: من الرئيسية «الربط مع أودو» (يحتاج صلاحية الربط). ويعمل في نسخة ويندوز فقط.

ملاحظات الإصدار الحالي:
- شيت المنتجات يقبل أعمدة وحدات القياس (UOM price/...) والكمية في اليد، ويُحدَّث من نفس الملف.
- التوقيع الرقمي للبرنامج: بعد شراء الشهادة أضف متغيرات CSC_LINK و CSC_KEY_PASSWORD كـ Secrets في GitHub (أو استخدم خدمة توقيع سحابية) وأخبرني لأضيف خطوة التوقيع في البناء.
