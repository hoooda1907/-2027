RMT System — خطوات الرفع على GitHub
1) أنشئ مستودعًا جديدًا فارغًا منفصلًا عن مستودع النسخة القديمة (لا تضعه في نفس المستودع).
2) ارفع كل محتويات هذا المجلد بنفس الأسماء والمسارات (بما فيها .github) ثم Commit.
3) Actions -> انتظر علامة ✅ -> Artifacts -> rmt-system-windows
   RMT-System-Setup.exe (تنصيب)  |  RMT-System-Portable.exe (بدون تنصيب)
- خطوة check في البناء تتوقف وتعرض الملفات الناقصة لو الرفع ناقص.
- البرنامج مستقل تمامًا عن النسخة السابقة: اسم مختلف ومعرّف تطبيق مختلف ومجلد بيانات مختلف، ويمكن تنصيبهما معًا.

مسار الحفظ: D:\RMT System (وإن لم يوجد القرص D فمجلد المستندات)

  المشتريات\الفرع\التاريخ\ "الفرع - المورد - التاريخ".xlsx
  المخزون\الفرع\التاريخ\
  العملاء\  الموارد البشرية\  الحسابات\
  النسخ الاحتياطي\  (تلقائي كل ساعتين)
